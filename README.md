# Командний календар

Невеликий додаток у стилі Google Calendar: кожен може **потягнути мишею по сітці тижня**, обрати зручний проміжок для зідзвону та підписати його своїм іменем. Проміжки різних людей **можуть накладатися** — вони розкладаються по сусідніх колонках, як події у Google Calendar. Дані спільні для всіх через бекенд, тож усі бачать одну й ту саму картину.

## Стек

- **Бекенд:** Node.js + Express, вбудована SQLite (`node:sqlite`) — без нативних залежностей. Потрібен Node ≥ 22.5 (перевірено на Node 25).
- **Фронтенд:** React + Vite.

## Запуск

```bash
npm install

# Режим розробки (фронтенд з гарячим перезавантаженням + бекенд):
npm run dev
# відкрий http://localhost:5173

# Або прод-режим (зібрати фронтенд і віддавати його з бекенду одним процесом):
npm run serve
# відкрий http://localhost:3001
```

Дані зберігаються у файлі `data.db` поряд із сервером.

## Як користуватися

1. Гортай тижні кнопками `‹` / `Сьогодні` / `›`.
2. Затисни ліву кнопку миші на сітці й потягни вертикально — виділиш проміжок (крок 30 хв).
3. Впиши ім'я → **Додати**. Ім'я запам'ятовується для наступних слотів.
4. Наведи на слот і натисни `×`, щоб видалити.

Слоти кожні 5 секунд підтягуються з сервера, тож зміни колег з'являються майже одразу.

## API

| Метод    | Шлях              | Опис                                       |
| -------- | ----------------- | ------------------------------------------ |
| `GET`    | `/api/slots`      | Список усіх слотів                          |
| `POST`   | `/api/slots`      | Створити: `{ name, start, end }` (ISO-час) |
| `DELETE` | `/api/slots/:id`  | Видалити слот                              |

## Налаштування

Видимий діапазон годин і крок сітки — у [src/lib/time.js](src/lib/time.js)
(`DAY_START_HOUR`, `DAY_END_HOUR`, `STEP_MIN`). Порт бекенду — змінна оточення `PORT`.
